# Thiranex Internship Task 3 — Exploratory Data Analysis (EDA)

## Objective
Explore data using statistical summaries, visualizations, correlation analysis, and a structured report.

## Dataset
`data/retail_sales_eda.csv` is a **synthetic sample dataset created for this learning project**, not official Thiranex data. If Thiranex supplied an official dataset, replace this CSV and rerun the analysis before submitting. Do not present sample findings as company facts.

## Features
- Dataset preview, dimensions, missing values and duplicate checks
- Descriptive statistics
- Revenue by category and region
- Monthly trend and revenue distribution
- Correlation matrix and heatmap
- Structured text report
- Streamlit dashboard

## Run in VS Code
```bash
python -m pip install -r requirements.txt
python src/eda_analysis.py
python -m streamlit run app.py
```

Correlation indicates association, not causation.
